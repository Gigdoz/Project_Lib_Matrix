# Project Library for working with matrices

## О проекте

- Открытые исходные файлы
- Сборка проекта на C++ с использованием CMake
- Для тестирования брался фрэймворк Catch2
- Данный проект содержит библиотеку lib для работы с матрицами и файл с тестами, проверяющие работу библиотечных функций

В библиотеке присутствуют два класса Matrix и наследующийся от него класс Vector.

## Реализация матричной алгебры и методы

Преопределенны все операции
- multiplication/operator 'in-place' *=
- multiplications on number/operator 'in-place' *= (on the number)
- division on number/operator 'in-place' /= (on the number)
- deff/operator 'in-place' -=
- addition/operator 'in-place' +=
- comparison ==

Есть методы:
- Получение размера
- Получение длины строки и столбца
- Заполение вектора или матрицы с помощью initializer_list ({x, y,..})
- Транспонирование
- Скалярное произведение для вектора
- Векторное произведение для вектора 3D
- Нахождение нормы

Дополнительно:
- Вывод в консоль

## Что можно добавить

- Преопределить оператор '>' и '<'
- Создать класс обертку единичная матрица
- Создать класс обертку вектор заполненный единицами
- Алгоритмы численного решения матричных уравнений
- Создание матриц и векторов вращения
